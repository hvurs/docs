## Open a ticket

Use the ticket panel posted by staff. Tickets open as private threads in the configured channel. If the panel is missing or you cannot access a ticket, contact server staff.

## Staff commands

Ticket staff can use `/ticket` commands to manage a ticket:

| Command | Purpose |
| --- | --- |
| `/ticket claim` and `/ticket unclaim` | Claim or release a ticket |
| `/ticket close` and `/ticket reopen` | Close a ticket or reopen it by number |
| `/ticket add user` and `/ticket remove user` | Change who can access the ticket |
| `/ticket rename` and `/ticket cat` | Rename a ticket or move it between categories |
| `/ticket escalate` | Restrict access to administrators and escalation staff |
| `/ticket anon` | Toggle anonymous moderator replies |
| `/ticket block` and `/ticket unblock` | Control whether a member can open tickets |
| `/ticket list` and `/ticket stats` | Review open tickets and staff activity |

Run `/ticket panel` in the channel where staff want to post an opening panel. Use `/help` or Discord's slash-command picker to see each command's required options.
