---
title: Admin Panel
description: "Manage server utilities from Caesar's unified admin panel."
icon: gear
---

Run `/admin` to open the server administration panel. Available sections depend on your staff permissions.

The panel includes:

| Section           | Use                                                                      |
| ----------------- | ------------------------------------------------------------------------ |
| Reaction Roles    | Add, inspect, and remove reaction-to-role mappings                       |
| Autoresponders    | Create, view, edit, enable, disable, and delete automatic replies        |
| AutoMod Whitelist | Manage the users, roles, or channels exempt from Caesar's AutoMod checks |

Choose a section in the panel and follow its prompts. Changes are saved when the panel confirms the action. If a section is not shown or an action is denied, ask a server administrator to review your access.
