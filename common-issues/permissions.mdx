---
title: Permission Issues
description: "Troubleshoot missing commands and failed actions."
icon: lock
---

If a Caesar command is missing or an action fails:

1. Type `/` and confirm you selected Caesar's command rather than a similarly named command from another app.
2. Check whether the command is staff-only. Ask an administrator to review your Caesar access.
3. Check Caesar's Discord permissions in the channel where you ran the command.
4. For role assignment, ensure Caesar has **Manage Roles** and its highest role is above the role it must assign.
5. For moderation actions, verify that Caesar's role is above the target member's roles and that the required Discord permission is granted.

If access still fails, share the command name and the exact error with server staff.
