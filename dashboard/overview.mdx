Open the [Nordicalls Dashboard](https://dash.hvurs.cc) and sign in with Discord. The dashboard uses Discord for authentication and shows pages based on your Nordicalls dashboard role. The server owner assigns staff roles; having a Discord server role alone does not automatically grant dashboard access.

## Member pages

### Home

View the dashboard home page and the live server list.

### Sanctions

Review your sanction records and open an individual case for its details. Staff-only case information is restricted to dashboard moderators and above.

### Lookup

Search Roblox profiles by username or Roblox ID. Lookup results can be opened as shareable links.

### My Applications and My Tickets

Review your own submitted applications and support tickets.

### Public application forms

Applications shared as a public form can be opened using their `/a/<code>` link. Sign-in is only required when that form's settings require it.

## Staff pages

| Dashboard role   | Available pages                                                                                            |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| Signed-in member | Home, sanctions, lookup, own applications and tickets                                                      |
| Moderator        | Member pages plus the read-only Users view                                                                 |
| Admin            | Moderator pages plus application management, staff management, and Caesar tools when API access is enabled |
| Owner            | All pages and controls, including managing dashboard admins                                                |

The **Users** view is for staff review. Search with a Discord ID or mention, Roblox username, or Roblox ID. Depending on the available records, it can show linked accounts, sanction and evidence history, staff notes, ticket information, and economy data. Views are read-only and recorded for audit. Application response details are restricted to admins.

Admins can review and manage applications, manage moderators, and use the Caesar dashboard tools when the owner has enabled API access for them. The owner manages dashboard admins and controls that API access.

## Caesar tools

The **Caesar** dashboard tools are available to the owner and admins granted Caesar API access.

### Bot blacklist

Add or remove a Discord account by ID or mention. A blacklisted account cannot use Caesar commands or interactions, enter giveaways, or access the dashboard. They can still use Caesar's ticket system in Discord.

### YouTube announcements

Configure automatic announcements for the latest videos from a YouTube channel in the dashboard; there is no separate YouTube slash command. Set the source to a channel ID, `@handle`, or channel URL; choose a Discord destination; and select a check interval from 5 minutes to 24 hours. The message template must include `{url}` and can also use `{title}`. Mentions in the template will not ping.

When first enabled, Caesar posts the channel's current latest video, then announces each new upload once. The settings page shows the last check, last posted video, and any recent error. Disable the automation there to stop announcements.

If a page is missing, your dashboard role may not include it. Ask a Nordicalls dashboard owner or admin to review your access.
