title: Slash Commands
description: "Use Caesar commands through Discord's slash-command interface."

---

Caesar's commands use Discord's slash-command interface. Type `/`, select Caesar, and then choose a command and its options. Discord shows each option's expected type and whether it is required.

Some commands use durations. Common examples include `30m` for 30 minutes, `2h` for two hours, and `1d12h` for one day and twelve hours. Use the format shown in the command's description.

If a command or panel section does not appear, see [Command access](/resources/permissions).
