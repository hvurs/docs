## Suggest an edit

<Steps>
  <Step title="Open the page">Go to the page you want to change.</Step>
  <Step title="Use the edit link">
    Select the edit option at the bottom of the page. It opens that page's
    source file on GitHub.
  </Step>
  <Step title="Make your change">
    Edit the text and submit it. GitHub will ask you to sign in and will create
    a copy of the repository for you.
  </Step>
  <Step title="Open a pull request">
    Describe what you changed and why. Your edit is only published after a
    maintainer reviews and merges it.
  </Step>
</Steps>

<Note>
  You need a free GitHub account to suggest an edit. Changes are never published
  automatically.
</Note>

## Raise an issue

If you are not sure how to fix something, open an issue instead. A useful issue includes:

- The page and section where you found the problem.
- What is wrong, or what you expected to see.
- The command or feature involved, if it applies.
- A screenshot, if it helps.

## Guidelines

- Keep changes focused. One fix per pull request is easier to review.
- Match the tone and formatting of the surrounding pages.
- Only describe features that exist in Caesar. Do not document commands you have not confirmed.
- Do not include tokens, private server details, or personal information.

Thank you for helping keep the docs accurate.
