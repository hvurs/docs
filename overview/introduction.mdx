Caesar is the Discord bot for the Nordicalls community. These guides describe the features available in that server.

<Info>
  Caesar uses Discord slash commands. Type `/` and choose Caesar to find commands available to you. Some commands and panel sections are restricted by staff permissions.
</Info>
