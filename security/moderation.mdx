---
title: Moderation
description: "Find and use the moderation commands available in Caesar."
icon: hammer
---

Caesar's moderation tools are slash commands. Type `/` in Discord and select Caesar, or run `/help`, to see the actions available to your account.

Access to moderation commands depends on the server's staff permissions. Discord also checks the bot's permissions and role position when an action requires them.

Before taking action, confirm the selected member and review the command's options. Commands that offer a reason should include enough context for other staff to understand the decision.

For destructive server actions, see the [security panel](/security/antinuke). For automated join protection, see [Anti-Raid](/security/antiraid).
