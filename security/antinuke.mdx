## Open the controls

Run `/security` and select **Anti-Nuke**. The panel shows whether protection is enabled, the punishment and time window, action limits, trusted accounts, and action exemptions.

From the panel, the server owner can enable or disable protection, edit its limits and general settings, add or remove trusted accounts, and change action exemptions.

<Warning>
  A trusted account is exempt from all anti-nuke checks. An action exemption skips only the selected action. Grant trust carefully.
</Warning>

Only the server owner can change anti-nuke settings. Members with anti-nuke view access can review the page; the panel only shows sections available to their permissions.

## What it protects

Anti-nuke watches configured destructive server actions and applies the configured response when an account exceeds its limit during the selected time window. Review the action limits in the panel and keep the trusted-account list current.
