## Configure join protection

Run `/security` and select **Anti-Raid**. The panel shows the current protection status and raid state. Authorized staff can configure:

| Setting | What it controls |
| --- | --- |
| Join limit and window | How many joins within the time window trigger raid protection |
| Minimum account age | Whether newly created accounts are blocked |
| Raid duration | How long raid mode remains active |
| Action | The response used for accounts that trigger protection |
| Channel locking | Whether channels are locked when raid mode starts |

Use the panel to review settings before enabling protection. The Anti-Raid section is only available to members with the required staff access.

## During a raid

The security panel reports whether raid mode is active. When a raid is detected, Caesar applies the configured response and may lock channels. Once the threat has passed, use the panel's raid controls to end the active state and review the channel permissions.
